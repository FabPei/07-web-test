# 07-web-test

Public **compiled-build mirror only** for mobile/browser testing of the private KaijuRTSDefend project.

Privacy rule:
- Do not commit Godot source files, scripts, design documents, raw assets, credentials or private project history here.
- The source project stays in the private `KaijuRTSDefend` repository.
- This repository is intended to contain only files produced by the Godot Web export plus `.nojekyll`.

Publishing is triggered manually from the private source repository through the `Publish Web Test` GitHub Actions workflow.
